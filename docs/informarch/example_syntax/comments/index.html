! многострочные комментарии в QSP реализуются немного иначе, чем в других языках программирования

! многострочный " комментарий, реализованный через выставление

! многострочный ' комментарий, реализованный через выставление
апострофов обратите внимание ' на текст до и после апострофов
*pl 'Если строка закомментирована - комментарий сломан'

! многострочный { комментарий, реализованный через выставление
фигурных скобок обратите внимание } на текст до и после фигурных скобок
*pl 'Если строка закомментирована - комментарий сломан'


! Теперь нужно показать, как работает комментарий с фигурными скобками {
	На каждую открытую скобку обязятельно должна приходиться одна зкарытая { { } }
	Помимо этого, если мы здесь внутри фигурных скобко используем апостроф ', у этого
	апострофа должен быть напарник '. То же самое касается "кавычек"
	Однако "внутри 'кавычек можно' помещать' апострофы" в любом количестве и наоборот
закрываем комментарий { } { } обязательно 
фигурной скобкой } но и после закрытия до конца строки комментарий продолжается.
*pl 'Если строка закомментирована - комментарий сломан'

! обратите внимание. " Если блок комментария ограничен кавычками
неважно сколько вы откроете фигурных скобок { { { или поставите
апострофов '' ' блок закончится кавычкой", а комментарий концом строки
*pl 'Если строка закомментирована - комментарий сломан'
