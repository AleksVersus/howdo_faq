# Comments

## singleline_comments

```qsp
! обыкновенный однострочный комментарий
*pl 'Если строка закомментирована - комментарий сломан'
! однострочный комментарий с "кавычками" внутри
*pl 'Если строка закомментирована - комментарий сломан'
! однострочный комментарий с "кавычками, в которых 'есть апостроф" не должен лоамть код
*pl 'Если строка закомментирована - комментарий сломан'
! однострочный комментарий с 'апострофами' работает
*pl 'Если строка закомментирована - комментарий сломан'
! однострочный комментарий с 'апострофами, в которых есть " кавычка' работает
*pl 'Если строка закомментирована - комментарий сломан'
! однострочный комментарий с {фигурными скобками}
*pl 'Если строка закомментирована - комментарий сломан'
! однострочный комментарий с {фигурными скобками, в которые помещена " кавычка} ломает подсветку
*pl 'Если эта и следующая строки закомментированы - комментарий работает правильно'
! теперь это не однострочный комментарий, закрываем кавычку " и скобку } дальше работает правильно
*pl 'Если строка закомментирована - комментарий сломан'

{! скобка в конце этого комментария не относится к комментарию, её положение однозначно}
{!@ скобка в конце этого комментария не относится к комментарию, её положение однозначно}

! коммментарий с } закрывающей скобкой в середине
*pl 'строка выше ^^^^^^^^^^^^^^^^^^^^^^^^^^ подсветится invalid, если комментарий сломан'

! амперсанд не & ломает обычный комментарий
*pl 'строка выше ^^^^^^^^^^^^^^^^^^^^^^^^^^ подсветится invalid, если комментарий сломан'
```

## multiline comments

```qsp
! многострочные комментарии в QSP реализуются немного иначе, чем в других языках программирования

! многострочный " комментарий, реализованный через выставление
кавычек обратите внимание " на текст до и после кавычек
*pl 'Если строка закомментирована - комментарий сломан'

! многострочный ' комментарий, реализованный через выставление
апострофов обратите внимание ' на текст до и после апострофов
*pl 'Если строка закомментирована - комментарий сломан'

! многострочный { комментарий, реализованный через выставление
фигурных скобок обратите внимание } на текст до и после фигурных скобок
*pl 'Если строка закомментирована - комментарий сломан'


! Теперь нужно показать, как работает комментарий с фигурными скобками {
	На каждую открытую скобку обязятельно должна приходиться одна зкарытая { { } }
	Помимо этого, если мы здесь внутри фигурных скобко используем апостроф ', у этого
	апострофа должен быть напарник '. То же самое касается "кавычек"
	Однако "внутри 'кавычек можно' помещать' апострофы" в любом количестве и наоборот
закрываем комментарий { } { } обязательно 
фигурной скобкой } но и после закрытия до конца строки комментарий продолжается.
*pl 'Если строка закомментирована - комментарий сломан'

! обратите внимание. " Если блок комментария ограничен кавычками
неважно сколько вы откроете фигурных скобок { { { или поставите
апострофов '' ' блок закончится кавычкой", а комментарий концом строки
*pl 'Если строка закомментирована - комментарий сломан'

! другие примеры многострочных комментариев

! многострочные комментарии " позволяют включать в себя несколько строк
	данный комментарий может "содержать кавычки, но в парном количестве". Если
	кавычек нечётное число, комментарий ломает весь остальной синтаксис. Точно
	так же это работает и в Quest Generator " кавычки кавычки
*pl 'Если строка закомментирована - комментарий сломан'

! тесты Оливера:

! "
   '
"
*pl 'Если строка закомментирована - комментарий сломан'

! '
   " 
'
*pl 'Если строка закомментирована - комментарий сломан'

! сломанный комментарий:
! {
	"
}
*pl 'Если строка закомментирована - комментарий работает правильно'
! закрываем кавычку коммента "
! закрываем скобку коммента }
*pl 'Если строка закомментирована - комментарий сломан'

! Ккккк " коментарий
И это комментарий " и это { всё
 ещё комментарий } комментарий ' комментарий
Прродолжается ' продолжается кончился
*pl 'Если строка закомментирована - комментарий сломан'

! Скобка { кавычка "
Игнорируемый апостроф ' дальше
Кавычка " скобка закрывается
} На следующей строке
*pl 'Если строка закомментирована - комментарий сломан'

dynamic {! многострочный комментарий "
изолирован внутри " блока кода
*pl 'Если строка закомментирована - комментарий сломан'
! {последняя скобка за комментарием закрывает блок,
   а неявляется частью комментария }}
*pl 'Если строка закомментирована - комментарий сломан'

! сломанный спецкомментарий:
!@ {
	"
}
*pl 'Если строка закомментирована - комментарий работает правильно'
! закрываем кавычку коммента "
! закрываем скобку коммента } коммент закончен
*pl 'Если строка закомментирована - комментарий сломан'

dynamic {!@ многострочный комментарий "
изолирован внутри " блока кода
*pl 'Если строка закомментирована - комментарий сломан'
!@ {последняя скобка за комментарием закрывает блок,
    а неявляется частью комментария }}
*pl 'Если строка закомментирована - комментарий сломан'
```

## multiline comments after `:`

```qsp
if 1: ! {
	msg 'Comment text'
}
	msg 'Executable code'
end
if 1: ! "
	Многострочный комментарий
"
	msg 'Исполняемый код'
end
```

## after_end

```qsp
! однострочный комментарий за end`ом
if 1:
	!pass
end эта строка текста игнорируется плеером

! комментарий оканчивается со следующей командой
if 1:
	!pass
end комментарий & *pl 'команда'
*pl "Если строка закомментирована, комментарий сломан"

! многострочный комментарий после end — через вложенные { }
if 1:
	!pass
end комментарий { открывается здесь
	и продолжается на следующей строке } до конца строки
*pl "Если строка закомментирована, комментарий сломан"

! & внутри {}, кавычек и апострофов НЕ прерывает комментарий.
if 1:
	!pass
end { & } " & " ' & ' комментарий продолжается & *pl 'а это уже команда'
*pl "Если строка закомментирована, комментарий сломан"

! Многострочный комментарий после end, оканчивающийся командой
if 1:
	!pass
end многострочный "
	комментарий " оканчивающийся & *pl 'рабочей командой'
*pl "Если строка закомментирована, комментарий сломан"

dynamic {! однострочный комментарий внутри скобок
if 1:
	!pass
end эта строка текста игнорируется плеером}

dynamic {! многострочный комментарий после end — через вложенные { }
if 1:
	!pass
end комментарий { открывается здесь
	и продолжается на следующей строке } до конца строки}

if 1:
	!pass
end !@ special comment " after
end " is correct & *pl "work"
*pl "Если строка закомментирована, комментарий сломан"
```

## Wrong comments

```qsp
! "
	{}
	''
	"""
"

let $string = "string"

" & ! <- выше комментарий ломает весь остальной код, и это правильно!
```

```qsp
{*pl 'код-код-код'

! комм{ }ентарий который ничего не ломает}

{act "привет":
	*pl 'Привет!'
end весь текст после правильного end является комментарием!}

{if 1:
	elseif 2: 234
	*pl "
		Все строки после правильного однострочного elseif
		или else являются полноценным комментариями, а точнее

	"
end}

	elseif 2: 234
	!@ *pl "
		Все строки после правильного однострочного elseif
		или else являются полноценным комментариями, а точнее
		просто игнорируются плеером!
	" здесь реализован спецкомментарий
```
