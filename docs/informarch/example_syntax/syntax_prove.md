# Проверка синтаксиса

Здесь приведены примеры наиболее распространённых случаев, когда требуется однозначное поведение подсветки синтаксиса. Ряд файлов предназначен для проверки, не сломалась ли подсветка. Ряд файлов предназначен для теста ошибок, подсвечиваемых подсветкой синтаксиса.

Иными словами этот раздел не относится напрямую к справочнику.
