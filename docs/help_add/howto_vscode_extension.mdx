# Расширение для MS Visual Studio Code (VS Code) {#rasshirenie_dlja_ms_visual_studio_code_vs_code}

Официальная страница расширения: [https://github.com/QSPFoundation/qsp-lsp](https://github.com/QSPFoundation/qsp-lsp)

Расширение для VS Code умеет:

- подсвечивать синтаксис файлов формата TXT2GAM (qsps/qsrc);
- подсвечивать различные ошибки синтаксиса QSP;
- анализировать код проекта, выявляя несоответствия и некоторые ошибки логики (например, локации с одинаковыми именами, одноимённые метки на локации и т.д.).
- быстро переходить по ключевым точкам проекта за счёт умной навигации между локациями и другим блокам кода.

## Установка расширения {#ustanovka_rasshirenija}

1. Скачайте последнюю версию со страницы релизов: [https://github.com/QSPFoundation/qsp-lsp/releases](https://github.com/QSPFoundation/qsp-lsp/releases) (файл **vsix**);
2. Откройте в VS Code панель расширений;
3. Перетащите скачанный файл vsix на панель расширений и дождитесь окончания устаноки.
